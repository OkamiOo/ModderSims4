# Modder Sims4

Un gestionnaire de mods pour Les Sims 4, gratuit et léger. Il trouve tes mods partout sur le PC,
les range par ordre de priorité, les active ou les désactive d'un clic, et lance le jeu avec les
mods bien activés.

## Ce qu'il fait

- Recherche sur tout le PC : les `.package`, les `.ts4script` et les archives de mods, sur
  tous les disques. Le CC, les mods et les mods de script sont reconnus et regroupés par mod ou
  par créateur.
- Un interrupteur par mod : un mod désactivé part dans un dossier de stockage, qui peut être
  sur un autre disque, et revient dans `Mods` quand tu le réactives.
- Liste triée toute seule : les bibliothèques (XML Injector, Sims 4 Community Library…)
  d'abord, puis les mods de base comme MCCC, puis le reste.
- Lancer le jeu : vérifie dans `Options.ini` que les mods et les mods de script sont activés,
  puis démarre Les Sims 4 (Steam ou EA app).
- Mettre à jour : téléchargement direct quand c'est possible, sinon la page du mod s'ouvre.
- Supprimer : après confirmation, le mod part dans la corbeille de Windows.

## Télécharger

Dans les [Releases](../../releases/latest) : prends `ModderSims4-x.y.z-portable.zip`, dézippe-le
et lance `ModderSims4.exe`. Rien à installer. Windows 10 ou 11.

Les nouvelles versions s'affichent à l'ouverture de l'appli, s'installent toutes seules et l'appli
se relance.
